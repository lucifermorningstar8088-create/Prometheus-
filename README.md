# Prometheus\n\nSecure, local-first autonomous personal operating agent.\n\n## Current status\n\nPrometheus now has a runnable foundation: task orchestration, deterministic planning, controlled project inspection/testing, verification states, bounded recovery, SQLite memory with provenance fields, audit logging, FastAPI API, and GitHub CI tests.\n\nThis is **not yet the final autonomous production agent**. The remaining phases include real model adapters, full PC sandboxing, browser isolation, encrypted secret storage, authentication, multi-agent workers, benchmark suite, red-team suite, scheduler, and production deployment hardening.\n\n## Run locally\n\n```powershell\npython -m venv .venv\n.\\.venv\\Scripts\\Activate.ps1\npip install -e ".[test]"\npython run.py\n```\n\nAPI: `http://127.0.0.1:8787`\n\n## API\n\n`GET /health`\n\n`POST /tasks` with `{ "goal": "inspect my project", "auto_execute": false }`\n\nSet `auto_execute` to true only for tasks covered by the current low-risk execution policy.\n\n## Safety\n\nPrometheus uses fail-closed principles. High-impact goals such as deployment, publishing, deletion, payments, and production changes are escalated instead of executed automatically by the current baseline.\n\nSee `PROMETHEUS_SPEC.md` and `SECURITY.md`.\n\n## Quality\n\nThe project must earn the >95% target through a reproducible benchmark. It is never treated as a blanket guarantee.\n
